## Рекомендации для оптимизации защиты данных 

- Внедрить опенсорсный инструмент `Apache Atlas` прост в обслуживании и существует экосистема Apache, чем большие системы обработки данных. 
- Применить симметричное шифровование `AES-256` для специальных полей в БД.
- Самошифрующиеся диски (SED) где хранятся данные в БД и `S3`
- Использование протокола HTTPS с `TSL 1.3`  при передачи данных. 
- Ограничивать описание Swagger-контрактов без моделей данных чувствительных
- Тэгировать данные при использовании `Apache Atlas`
- Внедрить модели разграничения доступа `ABAC` и `RBAC`
